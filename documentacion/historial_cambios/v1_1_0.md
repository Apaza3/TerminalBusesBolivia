## Módulo: Horarios y Selección de Rutas

### Descripción General
Módulo que permite a los usuarios buscar viajes de bus filtrando por Origen, Destino y Fecha.
Muestra resultados ordenados con rankings de sucursales (estrellas) y tags de amenidades
(WiFi, Bus Cama, Baño, TV, Aire Acondicionado).

### Cambios en Base de Datos
- **sucursales**: Se agregaron columnas `logo_url` (TEXT) y `amenidades` (TEXT[]).
- **viajes**: Se agregaron columnas `precio` (DECIMAL), `duracion_estimada` (TEXT), `estado` (TEXT).
- Script de migración: `backend/v1_1_migracion.sql`.

### Componentes Creados

#### BuscadorViajes.js (`frontend/src/paginas/BuscadorViajes.js`)
- Página con formulario de búsqueda: Origen, Destino, Fecha.
- Ciudades predefinidas: La Paz, Cochabamba, Santa Cruz, Oruro, Sucre, Potosí, Tarija, Trinidad, Cobija.
- Consulta Supabase con JOINs entre viajes, buses y sucursales.
- Incluye datos de demostración (hardcodeados) para visualización sin base de datos conectada.
- Manejo de estados: carga, sin resultados, y resultados encontrados.

#### TarjetaViaje.js (`frontend/src/componentes/TarjetaViaje.js`)
- Componente reutilizable para mostrar un viaje individual.
- Muestra: nombre sucursal, estrellas de ranking, ruta (origen → destino), hora, precio en Bs, duración, tags de amenidades.
- Botón "Seleccionar" preparado para futuro módulo de selección de asientos.

### Cambios en Archivos Existentes
- **App.js**: Navegación interna por estado (sin react-router) con barra de navegación superior.
- **Inicio.js**: Botón "Buscar Viajes" agregado, tags de amenidades visibles en tarjetas de sucursales.

### Estilos CSS
- **buscador.css**: Estilos desktop con paleta boliviana (azules profundos, grises andinos, acentos dorados).
- **buscador-responsivo.css**: Media query 768px, filtros apilados, botones táctiles grandes (optimizado Redmi Note 11S).

### Decisiones de Diseño
- **Navegación sin react-router**: Para minimizar dependencias externas en esta fase.
- **Datos de demostración**: Permiten verificar el diseño sin configurar Supabase.
- **Paleta de colores boliviana**: Azul profundo (#1a365d), gris andino (#4a5568), dorado (#d69e2e), verde (#38a169).
- **Mobile-First**: Diseño responsive optimizado para pantalla de 6.43" (Redmi Note 11S).
