# Historial de Cambios - v3.0.0 (Sprint V3 — Transaccional)
**Fecha:** 2026-04-01
**Módulo:** Sistema Transaccional (Tickets, WhatsApp, Dashboard Conductor, Timers)
**Rama:** `v3_terminal_buses`

---

## ✨ Nuevas Características

### 1. Generación de Tickets PDF + Código QR
- Módulo `TicketGenerator.js` utilizando `jsPDF` y `qrcode.react`.
- Genera un pasaje digital descargable en formato PDF.
- Incluye: Placa del bus, Nombre y CI del pasajero, Número de asiento, Código QR con ID de reserva.

### 2. Integración con WhatsApp
- Utilidad `whatsapp.js` para generar links `wa.me`.
- Botón "Enviar por WhatsApp" disponible en la pantalla post-reserva.

### 3. Dashboard del Conductor
- Nueva ruta protegida: `/conductor/panel` (solo rol `conductor`).
- Vista de la lista de pasajeros del viaje asignado.
- Controles: "Iniciar Viaje" (En Ruta) y "Finalizar Viaje" (Finalizado).

### 4. Limpiador de Asientos Pendientes (Timer)
- Hook personalizado `useSeatTimerCleaner`.
- Libera asientos "pendientes" automáticamente tras 15 minutos.

### 5. Almacenamiento Local (Mock)
- Módulo `mockStorage.js` con `localStorage` para Reservas, Estados y Timers.
