## Registro de Documentación
DOC-ERR-001: Fallo de Inicialización React (ENOENT)

Problema: Ejecución de npm start en directorio raíz sin package.json.

Causa: Creación manual de directorios sin andamiaje de create-react-app o npm init.

Solución Aplicada: Inicialización manual de npm en /frontend, instalación de react-scripts y generación de archivos raíz (index.html, index.js).

## Registro de Documentación
DOC-ERR-002: Error de Compilación Webpack (Module parse failed)

Problema: Al ejecutar npm start, Webpack falla indicando que 'import' y 'export' pueden usarse solo con 'sourceType: module'.

Causa: El archivo package.json generado por npm init incluía por defecto la propiedad "type": "commonjs", sobreescribiendo la configuración de módulos de react-scripts.

Solución Aplicada: Eliminación de la propiedad "type" en package.json, permitiendo que react-scripts procese correctamente los módulos.
